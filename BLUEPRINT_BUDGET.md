# The Nerve Hardware Budget

This document outlines the hardware costs for The Nerve. To make it easier to understand, the budget is split into **Component Base Prices** (the actual cost of the parts) and **Shipping & Taxes** (the fees to get them to Brazil).

Version A is the official submission for the Hack Club Tier 3 grant ($100 limit).

### 1. Component Base Prices (Version A - Round TFT)

| Part | Supplier | Price (USD) |
| :--- | :--- | :--- |
| ESP32-S3-DevKit-LiPo | Olimex | $8.70 |
| Custom PCB (5pcs) | JLCPCB | $4.00 |
| Toggle Switch Missile Cover | AliExpress | $3.73 |
| Outemu MX Switches (10pcs) | Shopee BR | $2.12 |
| K-Silver JH16 Hall Joystick (2x) | AliExpress | $8.12 |
| EC11 Rotary Encoder (10pcs) | AliExpress | $2.58 |
| JST-PH 2.0mm 2P Connector | AliExpress | $1.31 |
| Round TFT GC9A01 Display | AliExpress | $1.38 |
| LiPo 1800mAh 3.7V Battery | Shopee BR | $5.05 |
| SMD Components Batch | LCSC | $14.38 |
| **Subtotal Components** | | **$51.37** |

---

### 2. Shipping & Regional Taxes

These are the necessary shipping costs and taxes to deliver the components.

| Supplier / Fee Type | Cost (USD) |
| :--- | :--- |
| JLCPCB Shipping | $13.05 |
| LCSC Shipping (Global Direct) | $31.17 |
| AliExpress Taxes (ICMS) | $4.18 |
| Olimex / Shopee Shipping | $0.00 |
| **Subtotal Shipping & Taxes** | **$48.40** |

---

### 3. Final Total

| Version A | $51.37 (Parts) + $48.40 (Shipping/Taxes) | **$99.77** |
| :--- | :--- | :--- |

*(Note: Version B with a standard OLED SSD1351 brings the total to ~$119.40, and Version C with a premium OLED brings it to ~$121.20. Both exceed the Tier 3 limit and are for reference only).*
